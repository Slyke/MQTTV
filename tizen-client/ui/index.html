Samsung Tizen setup

This is the experimental Samsung Tizen package. Android APKs and Android Accessibility settings do not apply to this driver.

For SDK sideloading: open the TV Apps screen and enter 12345, enable Developer Mode, set the development computer IP, then restart the TV. Menu availability varies by model. Use Tizen Studio to connect and install a WGT signed with a certificate accepted by that TV.

The unsigned WGT is a build artifact, not a ready-to-install release. Physical-TV installation, runtime and standby behavior still require validation.

After installation, open MQTTV, configure MQTT and/or the API, save, and allow local-control pairing if prompted. Normal transport code uses the TV runtime and local control APIs, not ADB. Reopen MQTTV after a full restart; automatic startup is not verified.
